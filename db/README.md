# db フォルダ（SEIKA＋のデータベース定義）

GitHub の seika-plus リポジトリ直下（index.html と同じ階層）に置く。

| ファイル・フォルダ | 内容 | 本番で実行するか |
|---|---|---|
| 000_基準_2026-10.sql | 2026-10-04時点の本番DBの定義すべて。DBを作り直すときに使う | しない |
| 001_操作者名をログイン本人に固定.sql | 改善5。操作者名をログインした本人で記録する | 実行済みにする |
| 002〜 | 今後のSQL。番号を1つずつ増やして追加する | 番号順に1回ずつ |
| 調査/ | 読み取り専用のSQL（55番＝本番DBの書き出し） | 必要なときだけ |
| 旧/ | 2026-10以前のSQL（01〜52番）。参考として保管するだけ | しない |

## ルール
- 本番で実行したSQLは、必ずこのフォルダに番号つきで追加する
- ファイル名は「3けたの番号_内容.sql」（例：002_特別品目の記録を専用テーブルへ.sql）
- 実行した日付は docs/変更記録.md に1行追記する
